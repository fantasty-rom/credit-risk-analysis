# 消费信贷用户逾期行为分析与风控策略优化

基于15万条真实信贷数据的风控数据分析项目，从用户画像、逾期行为、规则评估三个维度展开深度分析，并提出可落地的风控策略优化建议。

## 项目背景

信贷风控的核心是在"通过率"和"坏账率"之间找到最优平衡。本项目基于真实消费信贷数据，通过数据分析挖掘逾期行为规律，评估现有风控规则效果，最终提出策略优化方案，帮助业务在控制风险的前提下提升审批效率。

## 数据说明

- **数据来源**：Kaggle Give Me Some Credit 竞赛数据集
- **样本量**：150,000条个人信贷记录
- **特征数**：10个输入特征 + 1个违约标签（90天以上逾期）
- **整体违约率**：6.68%

### 主要字段

| 字段 | 说明 |
|------|------|
| 年龄 | 借款人年龄 |
| 月收入 | 月收入金额 |
| 循环贷使用率 | 循环额度使用率（使用额度/总授信） |
| 负债比率 | 月负债/月收入 |
| 30-59天逾期次数 | 近两年30-59天逾期次数 |
| 60-89天逾期次数 | 近两年60-89天逾期次数 |
| 90天以上逾期次数 | 近两年90天以上逾期次数 |
| 未结清信贷笔数 | 当前未结清的信贷账户数量 |
| 是否违约 | 标签：是否出现90天以上逾期 |

## 项目流程

### 1. 用户画像分析 (`01_user_profile.py`)
- 按年龄、收入、负债比率、信贷笔数等维度拆解用户
- 分析各维度的样本分布与违约率差异
- 识别高风险人群特征

### 2. 逾期行为深度分析 (`02_overdue_analysis.py`)
- 逾期程度分层：无逾期/轻度/中度/严重
- 不同逾期程度用户的特征对比
- 滚动率分析：轻度→中度→严重的转化比例
- 识别催收关键节点

### 3. 风控规则策略评估 (`03_strategy_evaluation.py`)
- 单条规则效果评估：通过率、坏账率、拒绝精准度
- 组合规则策略对比：宽松/中等/严格三档策略
- 阈值分析：关键变量不同阈值的效果曲线
- 通过率-坏账率权衡分析

### 4. 策略优化建议 (`04_strategy_recommendation.py`)
- 核心发现总结
- 4条可落地的策略优化建议
- 用户风险分层矩阵（低/中/高三档）
- 可视化Dashboard

## 核心发现

### 1. 用户画像
- **年龄**：18-25岁违约率11.17%，65岁以上仅2.41%，相差近5倍
- **收入**：3k以下违约率9.43%，12k以上约4.5%，呈明显负相关
- **信贷笔数**：呈U型关系，0-2笔新人违约率最高（12.92%），6-8笔最低（5.35%）

### 2. 逾期行为
- **逾期分布**：79.8%无逾期，11.5%轻度，3.2%中度，5.6%严重
- **滚动率**：轻度→中度18.3%，中度→严重36.7%（中度逾期是催收关键节点）
- **严重逾期特征**：更年轻、收入更低、循环贷使用率更高

### 3. 规则效果
- **最强单规则**：循环贷使用率>90%（拒绝13%用户，坏账率下降36%）
- **次强规则**：有90天以上逾期记录（拒绝5.6%用户，坏账率下降31%）
- **反直觉发现**：负债比率单独使用效果差，需要和其他变量组合

### 4. 风险分层效果

| 风险等级 | 用户占比 | 违约率 | 风险倍数 |
|---------|---------|--------|---------|
| 低风险 | 69.4% | 1.97% | 1x |
| 中风险 | 14.7% | 10.09% | 5x |
| 高风险 | 15.9% | 24.09% | 12x |

## 策略优化建议

### 建议1：审批端 - 分层准入策略
- 高风险人群（年龄<25岁 + 循环贷使用率>80%）：人工审核或降额
- 中风险人群：正常审批，额度适中
- 低风险人群（年龄>50岁 + 无逾期记录）：自动审批，可提额
- **预期效果**：整体坏账率降低20-30%，通过率保持在80%以上

### 建议2：贷中管理 - 重点关注中度逾期客户
- 中度逾期客户滚入严重逾期的比例高达36.7%
- 建议在60天节点加大催收力度，提前介入
- 对有还款意愿的客户提供分期或展期方案
- **预期效果**：严重逾期率降低15-20%

### 建议3：新用户风险管理
- 0-2笔信贷记录的新人违约率高达12.92%（信用白户风险高）
- 建议新用户首笔额度降低，逐步提额
- 加强首贷前的信息验证和反欺诈核查
- **预期效果**：新用户坏账率降低25%

### 建议4：规则优化 - 用组合规则替代单规则
- 单条负债比率规则效果差（拒绝精准度仅6.5%）
- 建议：负债比率>100% 且 循环贷使用率>70% 才拒绝
- 可大幅降低误杀率，提升拒绝精准度
